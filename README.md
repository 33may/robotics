# robotics — VBTI

Robotics work done at VBTI. Three independent projects, each with its own environment, docs and README. They share no code.

| Project | What it is | Hardware |
|---|---|---|
| [`vbti/inspection`](vbti/inspection) | AI-driven general inspection: a vision-language model derives how to inspect an object from the question, instead of replaying a programmed path | UR5e |
| [`vbti/vla`](vbti/vla) | Framework for developing VLA policies: collection, dataset management, training, evaluation, sim scene creation. Includes the duck-cup SmolVLA case study | SO-101, 4× RealSense D405 |
| [`vbti/humanoid`](vbti/humanoid) | Humanoid project (stale) | LimX humanoid |

Start with the README of the project you need.
